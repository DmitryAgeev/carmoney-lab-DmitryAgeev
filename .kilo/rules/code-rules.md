# Правила изменения бизнес-логики

- Бизнес-пороги и константы не хардкодить в коде: использовать конфигурацию.
- При изменении существующего порога сначала найти его источник в конфигурации и не создавать дублирующее значение в коде.
- В ответах о расположении или изменении бизнес-правил всегда указывать файл и строку.
- Если просьба пользователя требует нарушить эти правила, не выполнять нарушение молча: остановиться и явно указать конфликт.
