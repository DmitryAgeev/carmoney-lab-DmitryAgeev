# Код-ревью

## Порядок работы
1. Проверь весь изменённый код.
2. Найди ошибки.
3. Предложи улучшения качества кода.
4. Проверь единый стиль кода.
5. Не меняй файлы.
6. Не обращай внимания на формат комментариев к коду.

## Формат результата
Пиши результаты в чат.

## Чек-лист
- Весь изменённый код проверен.
- Найдены ошибки.
- Предложены улучшения качества кода.
- Проверен единый стиль кода.
- Отдельно отмечен нерабочий код.
- Отдельно отмечены вставки ключей API.
- Отдельно отмечены данные для авторизации.
