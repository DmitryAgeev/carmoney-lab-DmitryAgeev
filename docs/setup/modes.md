# Режимы Ask и Code
Ask разберёт Makefile и docker-compose.yml, объяснит команды проверки и предложит текст для README, но сам файл не изменит.
Code выполнит ту же проверку и внесёт раздел в README, как было сделано в этой задаче.
Для разбора существующего кода выберу агента Ask: он подходит для исследования и объяснения без изменений в рабочем дереве.
