# E2E-проверка пробега

Адрес: `http://localhost:8080/`

## Пробег 400001

1. Открыт `http://localhost:8080/`.
2. В поле «Пробег, км» введено `400001`.
3. Нажата кнопка «Отправить заявку».
4. Система показала:

```text
Решение
Решение
review
LTV
50 %
Возраст авто
7 лет
Одобренный лимит
0 ₽
Номер заявки
25
```

Скриншот: `docs/setup/e2e_mileage_400001_review.png`.

## Пробег 600000

1. В поле «Пробег, км» введено `600000`.
2. Нажата кнопка «Отправить заявку».
3. Система показала:

```text
Заявка не принята
mileage: Пробег от 0 до 500000 км
```

Скриншот: `docs/setup/e2e_mileage_600000_error.png`.
