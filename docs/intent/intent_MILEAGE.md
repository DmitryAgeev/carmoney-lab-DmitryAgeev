# Замысел

Добавить в расчёт решения по заявке проверку пробега автомобиля: при пробеге не более 400000 км применяется обычный расчёт решения; иначе решение — `review`. (ответ в интервью)

# Constraints

- Пробег 400000 км включительно не должен переводить решение в `review`; при пробеге более 400000 км решение должно быть `review`. (ответ в интервью)
- Пробег в заявке должен быть от 0 до 500000 км включительно; при выходе за этот диапазон расчёт решения не выполняется. (код: `backend/src/Domain/ApplicationValidator.php`)
- Если пробег не указан, заявка не проходит валидацию и расчёт решения не выполняется. (код: `backend/src/Domain/ApplicationValidator.php`)
- Текущие решения по LTV: меньше 60.0 — `approve`; от 60.0 до 85.0 включительно — `review`; больше 85.0 — `reject`. (код: `backend/src/Domain/DecisionEngine.php`)
